# Лабораторная работа № 4 по дисциплине «Технологии программирования»

Обработка и визуализация данных библиотеками NumPy, Pandas и Matplotlib
в среде Jupyter Notebook. Индивидуальный вариант — **6**.

## Состав

| Файл | Содержание |
|---|---|
| `lab4_TP_NumPy_Tasks.ipynb` | Векторно-матричные задания NumPy: построение матриц M и N заданной структуры (85×85), векторов p и q, вычисление всех пяти выражений без циклов (основное по варианту — выражение 1). Все ячейки выполнены, ответы в выводах. |
| `lab4_TP_Pandas_Tasks.ipynb` | Анализ датасета о пассажирах «Титаника»: пропуски, подсчёты по маскам и группировкам, распределение Fare и выбросы, проверка пяти статистических утверждений, удаление Name, one-hot кодирование Sex, диаграмма рассеяния Age×Fare, min-max нормировка, парные гистограммы с общей осью абсцисс, выводы. |
| `titanic.csv` | Датасет (887 записей), используется ноутбуком; при отсутствии файл скачивается автоматически. |

Задания 2 и 4 Pandas-части содержат подпункты «в соответствии с вариантом»:
варианту 6 соответствует подпункт 1; в отчёте выполнены все подпункты.

## Технологии

Python 3, NumPy, Pandas, Matplotlib, Jupyter Notebook (.ipynb с
выполненными и прокомментированными ячейками).

## Как запустить

```powershell
pip install numpy pandas matplotlib
jupyter lab   # или открыть файлы .ipynb и выполнить Run All
```

В Google Colab ноутбуки открываются напрямую; датасет подтянется сам.
